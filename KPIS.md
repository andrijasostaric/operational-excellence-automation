# KPIs and Success Measures

| KPI | Why it matters | Example target |
|---|---|---|
| End-to-end onboarding cycle time | Measures overall process speed | Reduce by 30% |
| % requests returned for missing information | Shows intake quality | < 10% |
| % approvals completed within SLA | Shows responsiveness | > 90% |
| Manual status-chasing messages | Measures coordination overhead | Reduce materially |
| % active vendors with complete evidence | Supports audit readiness | 100% |
| % vendors with valid review date | Supports lifecycle control | 100% |
| Exceptions older than 5 working days | Highlights unmanaged blockers | 0 high-risk items |

## Measurement approach

Establish a baseline before automation, then compare performance after rollout. Improvements should be assessed on both efficiency and control quality; reducing cycle time is not a success if required review steps are bypassed.
